# Sine Wave Analysis

An analysis of drift rates of exoplanets from the NASA Exoplanet Archive (NEA) and asteroids to identify when they exhibit sinusoidal wave patterns.

## Overview

This project analyzes orbital drift rates and time-series data to detect periodic sine wave signatures in astronomical objects[cite: 15].

## Repository Contents

* `sin_curve.ipynb`: Main Jupyter Notebook containing data processing, drift rate calculations, and visualization[cite: 14, 15].
* `requirements.txt`: Python package dependencies required to execute the analysis.

## Getting Started

### Prerequisites

Clone the repository:
```bash
git clone [https://github.com/evanehn/sine-wave-analysis.git](https://github.com/evanehn/sine-wave-analysis.git)
cd sine-wave-analysis
```

Install required Python libraries:
```bash
pip install -r requirements.txt
```

### Running the Notebook

Launch JupyterLab or Jupyter Notebook:
```bash
jupyter lab sin_curve.ipynb
```
