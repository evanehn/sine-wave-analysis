# Sine Wave Analysis

An analysis of drift rates of exoplanets from the NASA Exoplanet Archive (NEA) and asteroids to identify when they exhibit sinusoidal wave patterns.

## Repository Contents

* `sin_curve.ipynb`: Main Jupyter Notebook containing data processing, drift rate calculations, and visualization.
* `upper_period_limit.ipynb`: Notebook analyzing upper period limits and rotational drift rates based on breakup periods.
* `requirements.txt`: Python package dependencies required to execute the analysis.
